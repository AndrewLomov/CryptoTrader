# ADR 001. Модульный монолит

## Статус

Принято

## Контекст

CryptoTrader 0.1 — одна торговая платформа с несколькими биржами и стратегиями в перспективе. Микросервисы, шина сообщений и CQRS не нужны для личного контура на одном VPS.

## Решение

Решение собирается как модульный монолит на Clean Architecture. Направление зависимостей — внутрь, к `CryptoTrader.Domain`. Конкретные адаптеры и `Program.cs` регистрируются только в `CryptoTrader.Host`. Mediator и отдельная шина доменных событий не вводятся: события лежат списком на агрегате и очищаются вызывающим кодом.

## Последствия

Новая биржа или стратегия — новый проект, а не правка домена. Сетевой вызов не выполняется внутри открытой транзакции БД. Пока в Host нет `Program.cs`, проект собирается как библиотека; с появлением `Program.cs` SDK снова делает его исполняемым веб-приложением.
