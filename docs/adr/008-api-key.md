# ADR 008. Ключ API и публичный health

## Статус

Принято

## Контекст

Управляющий API нельзя оставлять открытым. Проверка живости процесса и готовности базы нужна без секрета.

## Решение

`GET /health/live` и `GET /health/ready` анонимны. Ready зависит от PostgreSQL. Все маршруты `/api/v1/*` требуют заголовок `X-Api-Key`. Пустой `Api:AdminApiKey` останавливает запуск. DTO ответов лежат в `CryptoTrader.Contracts` и не содержат секретов. Prometheus-путь по умолчанию `/metrics` и не может начинаться с `/api`; наружу его не публикуют.

## Последствия

Host сравнивает заголовок с конфигурацией и не пишет ключ в логи. Отдельной пользовательской аутентификации в 0.1 нет.
