# ADR 007. Нативный клиент Bybit V5

## Статус

Принято

## Контекст

SDK биржи тащит чужие модели и не нужен, пока нет приватной торговли.

## Решение

В 0.1 Bybit подключается собственным REST/WebSocket-клиентом публичных методов V5. Пакет биржевого SDK не подключается. JSON Bybit не выходит за проект `CryptoTrader.Exchanges.Bybit`. В домен попадают уже нормализованные `Candle`, `Ticker`, `OrderBookSnapshot`, `Instrument`. Код адаптера — `BYBIT`, он совпадает с `ExchangeId.Bybit`. Интервал свечей `60` = 1h, `240` = 4h. Числа парсятся в `decimal`. Время биржи — миллисекунды Unix UTC. Лимит REST по умолчанию не чаще 10 запросов в секунду на клиент. Ошибка лимита не превращается в пустой успех. Подпись приватных заявок не реализуется.

## Последствия

Второй адаптер добавляется новым проектом поверх `Exchanges.Abstractions`. Приватный SDK можно рассмотреть только вместе с допуском к live.
