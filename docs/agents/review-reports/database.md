## Columns and table

`instruments`, all nullable:

| Column | Type |
|---|---|
| `contract_value` | `numeric` |
| `contract_value_currency` | `text` |
| `settlement_currency` | `text` |
| `contract_kind` | `text` |

`candles`:

| Column | Type |
|---|---|
| `volume_unit` | `integer not null default 1` |
| `quote_volume` | `numeric` null |
| `base_volume` | `numeric` null |

`candle_consumer_checkpoints` primary key `(exchange_id, instrument_id, timeframe, open_time_utc, consumer)`. Other columns: `state integer`, `updated_at_utc timestamptz`. No foreign key to `candles`. The only `ON DELETE CASCADE` relationships in the model remain backtest metrics and backtest trades. Deleting a checkpoint does not delete candles.

## Mapping

`InstrumentRepository.ToRow`, `Copy`, and `ToInstrument` read and write `ContractValue`, `ContractValueCurrency`, `SettlementCurrency`, and `ContractKind`. `ToInstrument` passes them as the trailing `Instrument.Create` arguments. Nulls are stored and loaded as null. Contract value is not defaulted to 1.

`CandleRepository` writes `VolumeUnit`, `QuoteVolume`, and `BaseVolume` on insert and on the update path of an existing row. `ToCandle` passes `VolumeUnit` (via `StoredEnum`, column `volume_unit`), `QuoteVolume`, and `BaseVolume`. Stored `1` is `VolumeUnit.BaseAsset`. `Volume` is not copied into `BaseVolume` or `QuoteVolume`.

`CandleConsumerCheckpoint` implements `ICandleConsumerCheckpoint` and is registered scoped in `AddPersistence`. `MarkPendingAsync` upserts `state = 1` and calls `SaveChanges`. `MarkProcessedAsync` upserts `state = 2` and calls `SaveChanges`. Only the candle and consumer passed in are written. Historical candles are not marked pending. `ListPendingCandlesAsync` joins `candle_consumer_checkpoints` to `candles` on exchange, instrument, timeframe, and open time, returns domain candles for `Pending`, ordered by `OpenTimeUtc` (then exchange, instrument, timeframe), limited by `limit`.

## Backup
